Frying an egg over a camp fire

Header area

Frying an egg on a campfire can be explained like a simple program because it follows clear steps in a specific order. The goal, or output, is a cooked egg, and the input is a raw egg, a pan, and a fire. If the steps are followed correctly, the result is predictable and successful.

One important variable in this process is heatLevel, which controls how fast the egg cooks. In programming terms, a variable is something that can change, and changing the heat changes the final result. If the heatLevel is too high, the egg burns, and if it is too low, the egg stays undercooked.

This cooking process works well because it requires paying attention and adjusting when needed. The steps are simple, but skipping one can cause the entire process to fail.

"Cooking is about paying attention."
— Alton Brown

The acronym CEP can be used to describe this simple method.
